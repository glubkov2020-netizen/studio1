Использование консоли

В разделе Console есть готовые команды:

  • count users — количество пользователей
  • count reviews — количество отзывов
  • current user — данные текущего пользователя
  • list collections — список коллекций с размерами
  • health check — проверка соединения

Безопасность

Правила безопасности Firestore и защита данных.

Firestore Rules

Правила доступа определяются в Firebase Console → Firestore → Rules.

rules_version = '2'; service cloud.firestore { match /databases/{database}/documents { match /reviews/{doc} { allow read: if true; } match /masters/{doc} { allow read: if true; } match /blog/{doc} { allow read: if true; } match /reviews/{doc} { allow create: if request.auth != null; allow update, delete: if isAdmin(); } function isAdmin() { return request.auth.token.email in ['glubkov2020@gmail.com']; } } }

Рекомендации

  • Никогда не коммитьте API-ключи в публичные репозитории
  • Ограничьте домены в Firebase Console → Authentication → Settings
  • Регулярно проверяйте логи на подозрительную активность
  • Используйте сложные пароли и 2FA для admin-аккаунтов
  • Делайте регулярные бэкапы Firestore
✅ Хорошо SSL Let's Encrypt включен, HSTS активен, TLS 1.3 — трафик защищен.

Деплой проекта

Как правильно выкладывать изменения на продакшн.

Методы

GitHub Pages

Тестовый домен. Push в main → автодеплой.

Reg.Host-Lite

Продакшн. Ручное обновление через FTP.

Процесс деплоя

  1. Внесите изменения локально
  2. Протестируйте на localhost
  3. git commit с понятным сообщением
  4. Push в GitHub
  5. Проверьте GitHub Pages через 1-2 минуты
  6. Загрузите на продакшн через FTP
⚠️ Перед деплоем Проверьте консоль браузера на ошибки.

Решение проблем

Частые ошибки и их решения.

Частые проблемы

❌ Firebase: permission denied

Проверьте Firestore Rules. Возможно, нет прав на чтение или запись.

❌ Auth: user not found

Пользователь удален или не существует.

❌ Страница не загружается

Проверьте консоль (F12). Причины: CORS, DNS, ad-blocker.

❌ Медленная загрузка

Большие коллекции. Используйте пагинацию.

❌ Ошибка 429

Превышен лимит. Подождите или увеличьте квоту.

💡 Диагностика Используйте разделы Network и Performance.
