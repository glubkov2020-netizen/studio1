Использование консоли

В разделе Console есть готовые команды для частых запросов:

  • count users — количество пользователей
  • count reviews — количество отзывов

  • list collections — список всех коллекций с размерами

Работа с Firestore

Firestore — это NoSQL-база данных от Google Firebase. Данные хранятся в коллекциях и документах.

Структура

Иерархия Collection → Document → Field → Value

Коллекции проекта

Просмотр данных

  1. Перейдите в раздел Firestore в боковом меню
  2. Нажмите Refresh чтобы загрузить актуальные данные
  3. Нажмите кнопку View напротив нужной коллекции
  4. Откроется модальное окно с первыми 50 документами в JSON-формате
✅ Совет Для больших коллекций используйте экспорт данных — полный дамп в JSON-файл.

Безопасность

Правила безопасности Firestore и защита данных.

Firestore Rules

Правила доступа определяются в Firebase Console → Firestore → Rules.

rules_version = '2'; service cloud.firestore { match /databases/{database}/documents { // Все могут читать публичные данные match /reviews/{doc} { allow read: if true; } match /masters/{doc} { allow read: if true; } match /blog/{doc} { allow read: if true; } // Только авторизованные могут писать match /reviews/{doc} { allow create: if request.auth != null; allow update, delete: if isAdmin(); } function isAdmin() { return request.auth.token.email in ['glubkov2020@gmail.com']; } } }

Рекомендации

  • Никогда не коммитьте API-ключи в публичные репозитории
  • Ограничьте домены в Firebase Console → Authentication → Settings
  • Регулярно проверяйте логи на подозрительную активность
  • Используйте сложные пароли и 2FA для admin-аккаунтов
  • Делайте регулярные бэкапы Firestore
✅ Хорошо SSL Let's Encrypt включен, HSTS активен, TLS 1.3 — трафик защищен.

Деплой проекта

Как правильно выкладывать изменения на продакшн.

Методы

GitHub Pages

Тестовый домен. Push в main → автодеплой.

Процесс деплоя

  1. Внесите изменения в код локально
  2. Протестируйте на localhost
  3. Сделайте git commit с понятным сообщением
  4. Push в репозиторий GitHub
  5. Проверьте GitHub Pages через 1-2 минуты

Решение проблем

Частые ошибки и их решения.

Частые проблемы

❌ Firebase: permission denied

Проверьте Firestore Rules. Возможно, у вашей учетной записи нет прав на чтение или запись.

❌ Auth: user not found

Пользователь удален или не существует. Проверьте UID в Firestore.

❌ Страница не загружается

Проверьте консоль браузера (F12). Возможные причины: CORS, DNS, блокировка рекламы.

❌ Медленная загрузка данных

Большие коллекции загружаются медленно. Используйте пагинацию или уменьшите размер данных.

❌ Ошибка 429 Too Many Requests

Превышен лимит запросов. Подождите или увеличьте квоту Firebase.

💡 Диагностика Используйте разделы Network и Performance для выявления узких мест.
